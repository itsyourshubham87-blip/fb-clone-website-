# Facebook Clone Website

This project is a **Facebook website clone** that I created while learning and practicing **Git and GitHub**. The main purpose of this project was to understand how Git works in a real development workflow and how to manage, track, and upload project files using GitHub.

## 📌 Project Overview

The Facebook Clone Website is a frontend project inspired by the basic layout and design of Facebook. It was created as a practice project to improve my understanding of **HTML, CSS, web page structure, styling, and Git version control**.

While building this project, I practiced creating a website structure, organizing project files, making changes to the code, and tracking those changes using Git.

## 🎯 Objectives

The main objectives of this project were:

* Learn the basics of Git and GitHub.
* Understand how to initialize a Git repository.
* Practice adding and committing project files.
* Learn how to push a local project to GitHub.
* Improve basic HTML and CSS skills.
* Understand how a social-media-style webpage is structured.
* Practice managing a project using version control.

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure of the webpage.
* **CSS3** – Used for styling and designing the interface.
* **Git** – Used for version control and tracking changes.
* **GitHub** – Used to store and manage the project repository.
* **VS Code** – Used as the code editor.

## 🔧 Git Workflow Used

During this project, I practiced a basic Git workflow:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <repository-url>
git push -u origin main
```

This helped me understand how a project can be created locally, tracked with Git, and then uploaded to GitHub.
